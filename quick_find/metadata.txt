description=Toolbar search box: type any value (e.g. MIN164) or a latitude, longitude, press Enter, and the map zooms to the matching feature or drops a temporary pin.
about=Searches every text field (and numeric fields for numbers) of the visible vector layers. Exact matches come first, then whole-word matches (MIN164 inside MIN_R3R3_ANL6_MIN164), then partial ones (MIN1640) only when nothing better exists. Press Enter again for the next match; the arrow button lists all matches and the options. Cmd+F (Mac) or Ctrl+F (Windows) jumps to the box and back to the map; Esc also returns to the map. While loaded, Quick Find takes that key from Layer > Filter… (still available in the Layer menu) and gives it back when unloaded. Type or paste a latitude, longitude (decimal like 7.119291, 125.6281, degrees-minutes-seconds like 7°07'09.4"N 125°37'41.2"E, or a Google Maps link) to zoom there and drop a temporary pin with the coordinates; the pin is not a layer and goes away when you clear the box or search again (or Remove pin in the menu). The Capture lat/long button lets you click the map to drop the pin there and copies its coordinates. From the ▾ menu, Add pin to layer saves the pin as a point in any point layer, filling Latitude/Longitude (or lat/long, x/y) fields and asking for a name when the layer has a name field; the layer is left in edit mode so you save or roll back the edit. The Street View button (or Open in Street View in the ▾ menu) opens Google Street View at the pin in your browser; only the pin coordinates are sent, and only when you click it. Attribute searches never edit layers. My location drops a pin where the computer is: Windows Location on Windows; on a Mac a Shortcuts-app shortcut (set up once, steps shown). Save pin keeps any pin (search, capture or my location) in a 'Saved pins' GeoPackage layer: a small Save window asks for name, remarks, colour and marker size (colour and size default to your last choice), and each pin is drawn as a Google-Earth-style pushpin in its own colour and size (Route Drawer's KMZ export uses Google Earth's own pushpin, tinted and scaled the same). Pins are saved into the group selected in the Layers panel (the selected group, or the group of the selected layer; the top level otherwise): each group keeps its own Saved pins layer and file (e.g. saved_pins_sub-group1.gpkg), made only when you press Save, and the Save window says where the pin goes. The Layers panel shows one entry per colour used, labelled with the pins in it (updated after each save or edit). If the top-level Saved pins layer was taken off the map, the next save starts a new dated file and says where the previous one is kept; ⚙ menu > Keep saved pins in… opens a file again, in the selected group. The point layer last used for Add pin to layer is remembered between sessions. Filter layers (funnel button) opens a panel to show only the features with a chosen value in a chosen column, e.g. one AN_Loop_Name, on the chosen layer and every other layer with that column; step through values with the arrows, optionally label and colour by a column; Clear restores each layer's own filter and style. Fast on big projects: each layer's names and IDs are read once and kept in memory (refreshed when the layer changes), layers over 200,000 features such as a whole-country roads layer are skipped unless you turn on 'Search large layers too', and the slower search of remarks/descriptions runs by itself only on small layers (otherwise a Search all fields button is offered). Works on QGIS 3.22+ (Qt5) and QGIS 4 (Qt6), on Windows and Mac.
